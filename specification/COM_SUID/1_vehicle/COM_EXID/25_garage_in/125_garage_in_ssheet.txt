# NOTES:
# ------

  `vh_vid` PK reuse:
  ------------------
  Legacy virtual garage didn't reused existing database records of retrieved vehicles.
  That means, if player retrieved vehicle from the garage, then returned it back -
  still within the same game session time - new database record was created.

  Now, we offer option to reuse already existing `vh_vid` and instead of `INSERT`
  we rather `UPDATE` already existing record with status `vh_sid = 0`.

  To make it work with SQF, each retrieved vehicle should store `vh_vid` variable with
  3rd argument set to `false` or not specified (no broadcasting).

  Original `vh_vid` may be reused as long as it happen within the same session time
  (vehicle variable `vh_vid` will NOT be known to server after restart, which means,
  status `vh_sid` remains `0` and will be removed from `th_table` on new session
  start (scheduled cleanup)).

  All this should be managed on arma server only. The only client requirement would be
  to pass `vh_vid` variable value with default value `0` (getVariable ["vh_vid", 0]);

  Also see : 'explain_th_select_reused_vh_vid.md'
             'explain_th_update_reused_vh_vid.md'
