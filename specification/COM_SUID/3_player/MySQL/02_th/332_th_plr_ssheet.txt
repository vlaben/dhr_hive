|                   |                   |                   |                  |        |                                               |                                   |
|                   |                   |                   |                  |        |                                               | Arma2OA server should get all     |
|                   |                   |                   |                  |        |                                               | `ph_uid` and `ph_gid` early -     |
|                   |                   |                   |                  |        |                                               | within server monitor right       |
|                   |                   |                   |                  |        |                                               | after hive system START           |
|                   |                   |                   |                  |        |                                               | (similary to objects/vehicle      |
|                   |                   |                   |                  |        |                                               | exports) and cache the result:    |
|                   |                   |                   |                  |        |                                               |                                   |
|                   |                   |                   |                  |        |                                               | gvar =                            |
|                   |                   |                   |                  |        |                                               | [                                 |

|                   |                   |                   |                  |        |                                               |           ["ph_gid",...]          |
|                   |                   |                   |                  |        |                                               | ];                                |
|                   |                   |                   |                  |        |                                               |                                   |
|                   |                   |                   |                  |        |                                               | This will speed up SQF code by    |
|                   |                   |                   |                  |        |                                               | avoiding query to figure out      |
|                   |                   |                   |                  |        |                                               | `ph_gid`.                         |
|                   |                   |                   |                  |        |                                               |                                   |

|                   |                   |                   |                  |        |                                               | `th_plr` record + "gvar" sync).   |
