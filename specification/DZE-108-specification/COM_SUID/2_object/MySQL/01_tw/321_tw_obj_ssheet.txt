+ ---------------------------------------------------------------------------- +
| related specs | DZE100_hive_world_naming_convention.txt                      |
|               | DHR100_hive_system.txt                                       |
|               | DHR200_hive_request_packet.txt                               |
|               | DHR300_hive_persistence_layer.txt                            |
|               | ------------------------------------------------------------ |
|   description | per-world unique table                                       |
|               | ------------------------------------------------------------ |
|         scope | subsystem object provider thread                             | com::suid::object
|               | ------------------------------------------------------------ |
|          name | tw_##_<worldname>_<suffix>_obj                               |
|               |                                                              |
|               | Examples:                                                    |
|               | ---------                                                    |
|               | tw_02_chernarus_w_obj                                        |
|               | tw_11_chernarus_s_obj                                        |
|               | ------------------------------------------------------------ |
|         rules | [R/01]                                                       |
|               | Each field is NOT NULL and defines default value;            |
|               |                                                              |
|               | [R/02]                                                       |
|               | Any non-restricted VARCHAR field whose definition depends    |
|               | on the server owner — and for which, consequently, exact     |
|               | parameter types cannot be defined at compile time — must     |
|               | be sent as a string:                                         |
|               | BAD : "[1,true]"      --> (i,b) --> expected: (s)            |
|               | GOOD: "\"[1,true]\""  --> (s)   --> expected: (s)            |
|               |                                                              |
|               | [R/03]                                                       | @TODO: consult with AirwavesMan
|               | Static weapons must not be stored in object table.           |
|               | Store them in vehicle table instead:                         |
|               | 1. they are technically vehicle class;                       |
|               | 2. they must track hitpoints (object doesn't have hitpoints) |
