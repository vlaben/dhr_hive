* State machine and subsystem server provider
  has capability to communicate with BE server
  via DHR Rcon client.
  ------------------------------------------------------
  State machine:
  [0] exclusive executor of the '#shutdown' command.
  ------------------------------------------------------
  Server administartors may use limited set of commands
  directly from game runtime session:
  ------------------------------------------------------
  [1] send global message to all players
  [2] send private message to specific player
  [3] reload scripts
  [4] reload events
  [5] set max ping
  [6] lock server
  [7] unlock server
  ------------------------------------------------------
